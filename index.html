Что мы собирали

Обе картинки нарисованы моделью Flux.2 Klein прямо в ComfyUI, без единого кадра из интернета.

Скачать воркфлоу

Файл нужно просто перетащить в окно ComfyUI — схема соберётся сама.

  • Мем: перерисовать людей в персонажей 5 вершин · с этого проще всего начать
  • Страница манги из трёх кадров 40 вершин · Canny, кроп лиц, баблы вторым проходом, сборка страницы

Как поставить себе

  1. Ставим Stability Matrix — он сам скачает и настроит ComfyUI
  2. В Stability Matrix: Packages → Add Package → ComfyUI
  3. Внутри ComfyUI включаем Manager и через него качаем модели
  4. Открываем скачанный .json — и жмём Run
